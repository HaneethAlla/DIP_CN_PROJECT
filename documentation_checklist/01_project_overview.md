

## 13-Class White Blood Cell Classification for Cancer Screening

The project investigates automated classification of peripheral-blood white blood cell (WBC) images into 13 fine-grained cell classes. The work is motivated by the potential use of WBC image analysis in leukemia screening and hematological research. The classification system is not intended to be used as a standalone clinical diagnostic tool.

The project combines Digital Image Processing (DIP) activities, including dataset inspection, image-level exploratory analysis and subsequent preprocessing, with a Computer Networks (CN) component in which a client can transmit a WBC image to a server for classification and receive the predicted class.

The project covers dataset verification, exploratory data analysis, image processing and segmentation work, classification workflow development, and Computer Networks integration.
