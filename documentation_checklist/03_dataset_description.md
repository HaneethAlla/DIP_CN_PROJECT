

The selected dataset is WBCBench 2026 — Robust White Blood Cell Classification, hosted on Hugging Face as `Xin-Tian/wbcbench2026`.

The dataset is a 13-class white blood cell image classification benchmark containing pristine and degraded images for robustness evaluation.

## The 13 WBC Classes

|Code|WBC Class|Description|
|---|---|---|
|SNE|Segmented neutrophil|Mature segmented neutrophil|
|LY|Lymphocyte|Lymphocyte|
|MO|Monocyte|Monocyte|
|EO|Eosinophil|Eosinophil|
|BA|Basophil|Basophil|
|VLY|Variant lymphocyte|Variant/atypical lymphocyte|
|BNE|Band-form neutrophil|Band-form neutrophil|
|MMY|Metamyelocyte|Metamyelocyte|
|MY|Myelocyte|Myelocyte|
|PMY|Promyelocyte|Promyelocyte|
|BL|Blast cell|Blast cell|
|PC|Plasma cell|Plasma cell|
|PLY|Prolymphocyte|Prolymphocyte|

Dataset link: [https://huggingface.co/datasets/Xin-Tian/wbcbench2026](https://huggingface.co/datasets/Xin-Tian/wbcbench2026)
